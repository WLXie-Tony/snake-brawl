# 蛇蛇乱斗

两台手机一起玩的 3D 联机贪吃蛇，用手机浏览器打开就能玩，不用装 App，也不用登录任何账号。

在线地址：https://wlxie-tony.github.io/snake-brawl/

## 怎么一起玩

1. 两个人都用手机浏览器打开上面的地址。
2. 一个人点「创建房间」，屏幕下方会出现 4 位房间号。
3. 另一个人在大厅「加入朋友的房间」里输入这个号，点「加入」。

两台手机连同一个 Wi-Fi 最稳，手机流量或公司网络下偶尔会连不上。

## 小提示

- 在手机浏览器里选「添加到主屏幕」，以后点图标就能全屏打开，用起来跟 App 差不多。
- 联机是两台手机直接相连，只借用一个公共服务器帮你们配对，房间号在房主退出后就失效。
